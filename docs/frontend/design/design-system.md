## Perfil admin

- Dashboard con KPIs y alertas.
- Accesos rápidos a citas, usuarios, inventario y reportes.
- Visual más densa y ejecutiva.

## Perfil barber

- Agenda del día y semana.
- Estado de ocupación.
- Clientes recientes y rendimiento.

## Perfil client

- Reserva rápida.
- Historial de citas.
- Perfil limpio con servicios y estado.
