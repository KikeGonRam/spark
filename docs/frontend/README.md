# Frontend

Base del frontend separado del backend FastAPI.

## Dirección visual

- Fondo oscuro: `#0a0a0a`
- Panel/card: `#141414` / `#111111`
- Acento: `#d4af37`
- Acento secundario: `#aa8c2c`
- Texto principal: `#ffffff`
- Texto secundario: `#b0b0b0`
- Bordes: `#333333`

## Perfiles

- `admin`: panel ejecutivo, KPIs, reportes, control del sistema.
- `barber`: agenda, disponibilidad, clientes, desempeño.
- `client`: reservas, historial, perfil, seguimiento.

## Estructura inicial

- `frontend/design/` tokens y guía visual
- `frontend/screens/` referencias de pantallas por rol
- `frontend/components/` piezas reutilizables
- `frontend/src/` arquitectura operativa del cliente

## Fases

1. Arquitectura base
2. Shells por rol
3. Integración API
